# Default coding worker role protocol

Within the coding assignment, complete investigation, implementation, focused validation and in-scope correction. Preserve role-specific checkpoints and owned paths; return complete results or a concrete blocker.

For managed workflow assignments, read the role protocol at
`{{roleProtocolPath}}`.

For managed work, if it is absent, unreadable, or names another role, return
`Status: role_protocol_blocked` and stop.
